# 🐍 Sistema de Cadastro de Clientes

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo
de praticar conceitos fundamentais de programação.

O programa permite informar os dados de um cliente
e visualizar as informações cadastradas no terminal.

## 🚀 Funcionalidades

- Solicitar o nome do cliente
- Solicitar a idade
- Solicitar o e-mail
- Exibir os dados informados

## 🛠️ Tecnologias utilizadas

- Python 3
- PyCharm
- Git
- GitHub

## ▶️ Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o projeto em uma IDE ou terminal.
4. Execute o arquivo:

python cadastro.py

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Variáveis
- Entrada de dados com input()
- Conversão de tipos com int()
- Saída de dados com print()
- Formatação de strings com f-strings
